# BFI-2 for Qualtrics

Ready-to-import [Qualtrics](https://www.qualtrics.com/) surveys for the **Big
Five Inventory-2** (BFI-2; Soto & John, 2017) and its short forms, with
automatic domain- and facet-level scoring built in.

The BFI-2 measures five personality domains — Extraversion, Agreeableness,
Conscientiousness, Negative Emotionality, and Open-Mindedness — each with three
facets.

## What's here

| File | Form | Items | Scores computed |
|---|---|---|---|
| `output/BFI-2_Full.qsf` | BFI-2 (full) | 60 | 5 domains + 15 facets |
| `output/BFI-2_Short.qsf` | BFI-2-S (short) | 30 | 5 domains + 15 facets |
| `output/BFI-2_ExtraShort.qsf` | BFI-2-XS (extra-short) | 15 | 5 domains |

Each file is a standalone survey with a working Qualtrics scoring
configuration, including correct reverse-coding of the 30 reverse-keyed items.
The extra-short form has no facet scores by design — its facets are single
items, for which the published BFI-2-XS defines domain scores only.

## Import into Qualtrics

1. In Qualtrics: **Projects → Create project → Survey → Import a QSF file**.
2. Choose one of the `output/*.qsf` files.
3. The survey and its scoring categories are created automatically. View them
   under **Survey → Scoring** (or the ⚙ scoring icon).

Responses export with one column per item plus one column per scoring category.
Scores are reported as **sums**; the standard BFI-2 convention is the *mean*
(divide a domain by its item count and a facet by its item count).

## Scoring

Scores use the official BFI-2 key (Soto & John, 2017): each domain is scored
from its 12 items (6 in the short form, 3 in the extra-short), each facet from
its 4 items (2 in the short form), with the 30 reverse-keyed items recoded.
The scoring is baked into the `.qsf` files, so no post-processing is needed
beyond the sum-to-mean conversion noted above.

The `output/` files were generated by the splitter tool in
`.claude/skills/bfi2-qsf-splitter/`, which injects the scoring by matching item
text against a master key verified against the official scoring documents. See
that directory for details.

## Tests

```
python3 -m unittest discover tests
```

Validates that every `.qsf` in the repo is well-formed, importable JSON. To
check a file's structural consistency in more depth:

```

```
